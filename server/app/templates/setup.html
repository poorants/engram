Connect a machine

Claude Code reaches this brain through a remote MCP server. The machine keeps no store address and no token of its own: you sign in once with Google, and Claude Code keeps and refreshes the credential.

Setup checklist

Tick a step when it is done — this browser remembers.

  1. Register the remote MCP server

    In a terminal on the machine:

    {{ cmd('claude mcp add --transport http --scope user --callback-port 33418 engram ' ~ mcp_url) }}

    No header and no token: the server is its own OAuth authorization server. --callback-port pins the port the browser returns to after login, so it can be forwarded over SSH (step 2).

    If an old stdio engram is registered, remove it first:

    {{ cmd('claude mcp remove engram -s user') }}

  2. Authenticate — once per machine

    In Claude Code run /mcp, choose engram → Authenticate. A browser opens; sign in with Google using an allowed account. Claude Code stores the token and refreshes it from then on.

    {{ ui.icon('terminal') }} Over SSH

    When Claude Code runs on a remote box and the browser is on your desktop, the login has to find its way back to port 33418 on the remote box.

    • VS Code Remote-SSH forwards the callback port automatically — nothing to do.
    • Plain ssh needs the port forwarded when you connect:
    {{ cmd('ssh -L 33418:localhost:33418 ') }}

  3. Finish the machine

    In a Claude Code session run:

    {{ cmd('/mcp__engram__setup', prompt='') }}

    It installs the engram plugin — the skill and the capture hooks — and the engram binary the hooks run. Then restart Claude Code.

    Manual equivalent

    The plugin:

    {{ cmd('claude plugin marketplace add https://github.com/poorants/engram') }} {{ cmd('claude plugin install engram@engram --scope user') }}

    The binary — macOS / Linux:

    {{ cmd('curl -fsSL https://raw.githubusercontent.com/poorants/engram/main/install.sh | sh') }}

    Windows (PowerShell):

    {{ cmd('irm https://raw.githubusercontent.com/poorants/engram/main/install.ps1 | iex', prompt='PS>') }}

  4. Check it works

    After the restart, /mcp lists engram as connected, and asking a session to search the brain answers from this store.

{{ ui.icon('question') }} Troubleshooting

The tools say “needs authentication”, even after the server was fixed
Claude Code remembers a server that once failed. Delete the engram key from ~/.claude/mcp-needs-auth-cache.json and restart Claude Code.
Nothing answers at the MCP address
The server has to be reachable from the machine — it lives on the tailnet, so the machine must be on it too. Any HTTP answer, even a 401, means it is reachable:
{{ cmd('curl -sI ' ~ mcp_url) }}
The login finishes in the browser but Claude Code never hears of it
The callback did not reach port 33418. Over plain ssh, reconnect with -L 33418:localhost:33418 (step 2).
Starting over
claude mcp remove engram -s user also deletes the stored OAuth token. Add the server again (step 1) and authenticate.
